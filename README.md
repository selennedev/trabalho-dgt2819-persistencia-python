# Trabalho Prático — DGT2819: Persistência de dados com Python

## Objetivo
Ler um arquivo de texto, separar seu conteúdo em palavras, comparar Bubble Sort,
Selection Sort e a ordenação nativa do Python, medir o tempo de execução e gravar
as palavras ordenadas em outro arquivo.

## Arquivos
- `kdd.py`: código principal.
- `texto.txt`: texto de entrada de exemplo.
- `palavras_ordenadas.txt`: será criado automaticamente ao executar o programa.

## Como executar
1. Instale o Python 3, se necessário.
2. Abra esta pasta no VS Code.
3. Abra o terminal integrado.
4. Execute:

   ```bash
   python kdd.py
   ```

   No Windows, se o comando acima não funcionar, tente `py kdd.py`.

5. Confira os tempos e as palavras exibidas no terminal.
6. Abra `palavras_ordenadas.txt` para conferir o resultado salvo.

## Como personalizar
Substitua o conteúdo de `texto.txt` por outro texto, salve o arquivo e execute
`kdd.py` novamente. Mantenha os dois arquivos na mesma pasta.

## Observação
Os tempos variam conforme o computador e o tamanho do texto. Para uma comparação
mais representativa, teste também com um arquivo de entrada maior.
